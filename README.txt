SYNTHETIC PLANT XYLEM YOLOv8 DATASET
======================================

250 microscopy-like images with YOLO bounding-box labels.

Classes:
0 vessel
1 fiber
2 parenchyma

Split:
175 train
37 validation
38 test

Image size: 512x512 JPG
Format: YOLO detection labels

IMPORTANT:
This dataset is procedurally generated synthetic data for testing the
YOLOv8 pipeline, folder structure, annotation loading, training code,
and demonstrations. It is NOT a collection of real microscope images
and must not be represented in a research paper as real biological
observations or as experimental evidence.

For the final paper/project results, use real plant-stem micrographs
with expert-reviewed annotations.
